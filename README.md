## About
TaskFlow is a simple Android to-do app built with React Native Expo and NativeWind. Tasks are saved locally using AsyncStorage so they persist even after closing the app.

## Features
- Add, complete, and delete tasks
- Mark all tasks as done
- Delete all completed tasks
- Stats panel showing Total, Done, and Pending
- Data saved with AsyncStorage

## Tech Used
- React Native + Expo
- NativeWind (Tailwind CSS)
- AsyncStorage
- Remix Icons

## How to Run
```bash
npm install
npx expo start --clear
```
Scan the QR code with Expo Go on your Android device.
